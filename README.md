# Diplom 3. Автотесты для UI веб-приложения Stellar Burgers
Проект содержит автоматизированные тесты UI веб-приложения Stellar Burgers

## Задание
- Опиши элементы, которые будешь использовать в тестах, с помощью Page Object.
- Протестируй функциональность в Google Chrome и Яндекс Браузере. Подключи Allure-отчёт.

## Что протестировано
### Регистрация
- Проверка успешной регистрации.
- Проверка ошибки для некорректного пароля. Минимальный пароль — шесть символов.
### Вход
- Проверка входа по кнопке «Войти в аккаунт» на главной;
- Проверка входа через кнопку «Личный кабинет»;
- Проверка входа через кнопку в форме регистрации;
- Проверка входа через кнопку в форме восстановления пароля.
### Раздел «Конструктор»
Проверка, что работают переходы к разделам:
- Проверка работоспособности переходы к разделу «Булки»;
- Проверка работоспособности переходы к разделу «Соусы»;
- Проверка работоспособности переходы к разделу «Начинки».

# Запуск проекта и генерация отчетов
Очистка проекта и запуск автотестов в YandexBrowser:
```
mvn clean compile test -Dbrowser=yandex "-Dallure.results.directory=target/allure-yandex-results"
```
Очистка проекта и запуск автотестов в Google Chrome:
```
mvn clean compile test -Dbrowser=chrome "-Dallure.results.directory=target/allure-chrome-results"
```
Генерация статичного HTML-отчета Allure: 

```
mvn allure:report "-Dallure.results.directory=allure-chrome-results"
mvn allure:report "-Dallure.results.directory=allure-yandex-results"
``` 

Готовый отчет можно открыть вручную через файл ```target/site/allure-maven-plugin/index.html```.
Запуск интерактивного Allure-сервера в браузере: 
```
mvn allure:serve
```
# Управление тестовыми данными
Все тесты абсолютно независимы. Создание сущностей происходит динамически перед каждым тестом, 
а в методах @After реализована гарантированная зачистка базы данных, что предотвращает замусоривание учебного стенда.
